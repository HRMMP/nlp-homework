# 命名实体识别实验要求

## 任务目标

根据课程作业要求，本实验需要：

1. 了解命名实体识别（Named Entity Recognition，NER）的相关知识。
2. 了解 BERT 的相关知识。
3. 了解本实验的过程及其评价标准。

## 入门学习资料

如果你对 NLP 和深度学习基础不熟悉，建议先按 [`learn/README.md`](./learn/README.md) 的顺序阅读。资料覆盖 NER、BIO 标签、subword 对齐、BERT、微调和实体级指标，并包含实现前的自测题。


实现和说明中应重点关注以下内容：

- 命名实体识别的任务背景及应用。
- BERT 的基本结构和预训练思想。
- BERT 的输入表征，包括 Token Embeddings、Segment Embeddings 和 Position Embeddings。
- 基于 BERT 的 Token Classification：对输入序列的各个位置进行分类并预测实体标签。
- BIO 或 BIOES 标注方式及实体类别说明。
- 预训练模型在下游命名实体识别任务上的微调过程。

## 评价要求

至少报告以下指标：

- Precision（准确率）。
- Recall（召回率）。
- F1 Score。

报告中应说明指标的计算方式和评价配置，并结合实验结果进行分析。不能只使用单一的分类准确率替代上述指标。

## 报告中应包含

- 实验背景和问题介绍。
- 当前研究现状。
- 模型与算法设计。
- 实验结果与分析。
- 总结。
- 组员具体分工。

## 依据

本要求整理自根目录的 `自然语言处理大作业.pdf`，具体数据集、标签集合、预训练模型和实验参数需根据实际实验方案确定并如实记录。
