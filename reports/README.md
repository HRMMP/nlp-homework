# 实验报告初稿

[实验报告模板.tex](./实验报告模板.tex) 已写入背景和问题介绍、研究现状及候选参考文献；数据集、具体实现方案、实验结果和组员信息仍保留待填项。仓库附有当前初稿的 [PDF 预览](./实验报告模板.pdf)。

在仓库根目录编译：

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error \
  -outdir=reports/build reports/实验报告模板.tex
```

请按实际实验填写红色“待填写”项；没有运行、没有记录或无法核验的内容要明确注明，不要补造数据、指标、引用或组员分工。当前初稿中，模型和数据的具体配置、实验结果与误差分析仍待补充；参考文献条目也须对照原文或官方记录人工核验。提交前应移除模板提示文字，并确保正文论述、引用和实验记录一致。

每组 3 人。课程要求的提交邮箱为 `nlp_course_ustc@163.com`。提交文件名格式为：

```text
26年秋实验报告_第x组_组长姓名_组长学号
```
