# 大模型参数高效微调实验要求

## 任务目标

根据课程作业要求，本实验需要：

1. 了解大模型的相关知识。
2. 了解 LoRA（Low-Rank Adaptation）的相关知识。
3. 了解本实验的过程。

## 入门学习资料

如果你对大语言模型和深度学习基础不熟悉，建议先按 [`learn/README.md`](./learn/README.md) 的顺序阅读。资料覆盖语言模型生成、提示词、LoRA、参数冻结、数学答案抽取和 Accuracy，并包含实现前的自测题。


实现和说明中应重点关注以下内容：

- 生成式预训练模型的基本概念。
- GPT 类生成式预训练模型的基本结构。
- InstructGPT 及指令微调的基本思想。
- LoRA 的低秩适配原理。
- 在预训练模型基础上增加少量可训练参数进行任务适配，而不直接修改原始模型权重。
- 数学题目的模型输入、输出和答案判定过程。

## 评价要求

在测试集上统计准确率（Accuracy），并在报告中说明：

- 测试集的使用方式。
- 数学题答案的抽取方式。
- 答案是否正确的判定规则。
- 最终准确率及其分析。

## 报告中应包含

- 实验背景和问题介绍。
- 当前研究现状。
- 模型与算法设计。
- 实验结果与分析。
- 总结。
- 组员具体分工。

## 依据

本要求整理自根目录的 `自然语言处理大作业.pdf`，具体基础模型、数学数据集、LoRA 配置和训练参数需根据实际实验方案确定并如实记录。
