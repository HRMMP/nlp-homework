# LoRA 数学微调学习路线

本目录面向几乎没有深度学习和大语言模型基础的读者，目标是帮助你理解“给一个预训练生成模型添加 LoRA 适配器，并在数学题测试集上评估”的完整流程。

## 推荐顺序

1. [语言模型、提示词和生成](./01_llm_and_generation.md)：理解模型输入什么、如何逐 token 生成答案。
2. [LoRA 与参数高效微调](./02_lora.md)：理解冻结基础模型、低秩更新和可训练参数。
3. [数学任务、答案抽取与评估](./03_math_eval.md)：理解数据划分、训练目标、生成结果和准确率。

## 你需要先会什么

- Python 基础和命令行基础。
- 向量、矩阵乘法和神经网络参数的基本概念。
- 训练集、验证集、测试集的区别。
- 能读懂配置中的 batch size、learning rate、epoch、max length 等字段。
- 对显存、模型大小和 batch size 之间的关系有基本认识。

## 完成实验前的知识检查

你应该能够解释：

- 预训练语言模型为什么能够根据上下文预测下一个 token。
- “指令微调”与普通语言模型预训练有什么区别。
- LoRA 训练时哪些参数被冻结，哪些参数会更新。
- `r`、`alpha`、`dropout` 和 target modules 分别控制什么。
- 为什么测试集不能参与训练或提示模板调参。
- 一个数学题的“生成文本”如何被转换为可复核的最终答案。

## 和后续代码的对应关系

| 学习概念 | 实现时通常对应 |
| --- | --- |
| prompt 模板 | 数据预处理和 tokenizer 输入 |
| causal language modeling | 训练标签与 shifted loss |
| LoRA adapter | PEFT 配置和可训练参数检查 |
| generation | 推理脚本及生成参数 |
| answer extraction | 从模型文本中解析最终答案 |
| exact/normalized match | 单题判分规则 |
| independent test set | 最终 Accuracy |

基础模型、数学数据集、提示模板、LoRA 目标模块和训练参数都需要实际选择并记录。若硬件无法支持完整训练，应如实记录限制，不能把小规模试运行当成正式结果。

## 建议的学习方式

先用一条样本检查 prompt、标签和答案抽取，再检查模型是否真的只有 LoRA 参数可训练。正式评估时保存原始题目、参考答案、模型生成文本、抽取答案和判分结果，便于重新计算指标。
